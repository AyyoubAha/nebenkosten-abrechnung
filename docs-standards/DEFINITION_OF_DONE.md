# Definition of Done

Eine Aufgabe ist fertig, wenn:
- alle drei Prüfungen grün sind (engine.test, e2e nach frischem Pro-Build, copy-lint),
- die Punkte aus PRODUCT_QUALITY_STANDARD.md erfüllt sind,
- die Änderung im Haupt-Repo (GeldMacher, products/nebenkosten/repo/) liegt und von dort
  in dieses Repo gespiegelt und gepusht wurde,
- bei Änderungen am Kaufartefakt die neue ZIP auf beiden Verkaufskanälen liegt,
- die Live-Seite nach dem Pages-Deploy stichprobenartig geprüft wurde.

Ein grüner Build allein ist kein Nachweis für visuelle Qualität: Bei Gestaltungsänderungen
gehören Screenshots (1440, 1280, 768 und 390 Pixel Breite) zum Nachweis.
